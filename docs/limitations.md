# Limits of these labs

- Data, tenant identities, policies, approvals and business actions in the required track are synthetic. Trusted Python Context injection is not authentication or real human review.
- Application tenant predicates/composite keys do not protect against a hostile operator with database-file access.
- The default planner and specialist routing are deterministic simulations. Lexical retrieval is not semantic retrieval, and the narrow injection sample detector is not a general defense.
- Case creation is local. The separate outbox destination is another local SQLite file with injected failures and key/digest receipts. No real external transaction or distributed exactly-once guarantee is established.
- Memory has scoped stale checks and explicit deletion, without a production retention/backup-erasure service. There is no rolling migration manager or distributed worker fencing.
- Budgets bound local steps/requests/output configuration. No paid-provider adapter, financial ledger or broad model benchmark is included.
- Optional live inference is explicitly gated, with version-specific results kept separately from the source snapshot. Schema conformance is not semantic correctness. No hidden reasoning should be logged.
- UCI transaction-line aggregates prove neither physical returns, current inventory, delivery nor recognized revenue. No raw customer identifiers are bundled.
- Hosted CI is static only; production identity, queues, egress, load/SLA, incident handling and external-service recovery need environment-specific design and testing.

Book manuscripts, covers, illustrations, diagram/build sources, private audit evidence and historical reports are excluded. The original lab software license does not relicense external data, model weights, runtimes or upstream notices. This export awaits its coordinated review rounds before publication.
